# ApplyFill

Save your details once, then start job applications without typing the same answers again.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

Add your Supabase project URL and publishable key to `.env.local`. Apply `supabase/migrations/20260926140000_foundation_schema.sql` in the Supabase SQL editor before creating an account.
